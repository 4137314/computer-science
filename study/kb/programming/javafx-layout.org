#+title: JavaFX layout panes
#+summary: Instead of positioning nodes by coordinates, one puts them in layout panes that compute positions and sizes automatically and recompute them when the window is resized: HBox/VBox in a row or column, BorderPane in five regions, GridPane in a grid, StackPane on top of each other.

* Definition
| pane | arrangement |
|---+---|
| =HBox=, =VBox= | horizontal row, vertical column (spacing, padding, alignment) |
| =StackPane= | children on top of each other, centred |
| =FlowPane= | flows and wraps, like text |
| =TilePane= | grid of equal cells |
| =BorderPane= | top, bottom, left, right, centre |
| =GridPane= | grid of rows and columns, with spans; =add(node, col, row)= |
| =AnchorPane= | children anchored at distances from the edges |

Panes nest: a =BorderPane= with a =VBox= of buttons on the left and a =GridPane= in the centre. Manual adjustments remain possible: =setLayoutX= or =setTranslateX= move a node, =setPrefWidth=, =setMinWidth=, =setMaxWidth= constrain its size.

* Example
#+begin_src java
  GridPane form = new GridPane();
  form.setHgap(8); form.setVgap(8);
  form.add(new Label("Name"), 0, 0);  form.add(new TextField(), 1, 0);
  form.add(new Label("Age"), 0, 1);   form.add(new TextField(), 1, 1);
  BorderPane root = new BorderPane(form);              // form in the centre
  root.setBottom(new HBox(10, new Button("OK"), new Button("Cancel")));
#+end_src

* Intuition
Describe relations ("these in a row, that at the bottom") and let the pane do arithmetic; the result survives resizing and different screens.

* Pitfall
A node can have one parent only: adding it to a second pane removes it from the first, silently.
