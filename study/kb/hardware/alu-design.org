#+title: Arithmetic logic unit
#+summary: One adder plus "B input conditioning" (pass \(B\), \(\bar B\), 0 or all ones) and the carry-in implements add, subtract, increment, decrement and transfer; a logic unit computes AND, OR, XOR, NOT bitwise; a function-select code chooses the operation, and flags \(N,Z,C,V\) report the result.

* Construction
Arithmetic: \(G=X+Y+C_{in}\) with \(X=A\) and \(Y\) chosen by \(S_1S_0\):

| S1 S0 | Y input | Cin = 0               | Cin = 1               |
|-------+---------+-----------------------+-----------------------|
| 0 0   | all 0   | G = A (transfer)      | G = A + 1 (increment) |
| 0 1   | B       | G = A + B (add)       | G = A + B + 1         |
| 1 0   | not B   | G = A + B̄ = A − B − 1 | G = A − B (subtract)  |
| 1 1   | all 1   | G = A − 1 (decrement) | G = A (transfer)      |

Each bit of the conditioning logic is \(Y_i=B_iS_0+\bar B_iS_1\). Logic: a 4:1 mux per bit selects \(A\wedge B\), \(A\vee B\), \(A\oplus B\), \(\bar A\). A further select chooses arithmetic, logic or shifter output.

Flags: \(N=G_{n-1}\), \(Z=\overline{\bigvee_i G_i}\), \(C=c_n\), \(V=c_n\oplus c_{n-1}\) (signed overflow).

* Example
#+begin_src vhdl
  with fs select
    g <= std_logic_vector(unsigned(a) + unsigned(b))          when "0010",
         std_logic_vector(unsigned(a) - unsigned(b))          when "0101",
         a and b                                              when "1000",
         a or b                                               when "1010",
         a xor b                                              when "1100",
         not a                                                when "1110",
         a                                                    when others;
  z <= '1' when unsigned(g) = 0 else '0';
#+end_src

* Intuition
Subtraction, increment and decrement are all addition with a different second operand and carry-in: one adder, a little input logic, many operations.

* Pitfall
\(C\) and \(V\) mean different things: \(C\) is the overflow of unsigned arithmetic (and, for subtraction, the inverted borrow), \(V\) the overflow of signed arithmetic. A comparison must use the right one.
