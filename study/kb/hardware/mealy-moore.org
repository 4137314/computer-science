#+title: Mealy versus Moore machines
#+summary: In a Moore machine the outputs depend only on the present state, so they are written inside the states, are constant for the whole clock cycle and react to an input one cycle late; in a Mealy machine they depend on state and inputs, are written on the arrows, react within the same cycle and often need fewer states — but they follow input glitches and two Mealy machines connected in a loop can close a combinational cycle.

* Definition
- *Moore*: \(OUT(n)=\Lambda(X(n))\). Output logic fed by the flip-flops only.
- *Mealy*: \(OUT(n)=\Lambda(IN(n),X(n))\). Output logic fed by flip-flops and inputs.
Every Moore machine is a Mealy machine whose outputs ignore the inputs; a Mealy machine is converted to Moore by splitting each state according to the output with which it is entered (more states, one cycle later).

* Example
Boiler (inputs \(H\), \(L\); output \(C\); state \(X\)=burner on).
Moore: \(X^+=L+X\bar H\), \(C=X\). The burner switches on in the cycle *after* \(L\) is seen, when the state has become 1.
Mealy: same next-state function, \(C=L+X\bar H\): the burner switches on in the same cycle in which \(L\) rises — \(C\) equals the next state instead of the present one.
Timing, \(L\) rises in the middle of cycle 2:

| cycle      | 1 | 2 | 3 | 4 |
|------------+---+---+---+---|
| L          | 0 | 1 | 0 | 0 |
| X (state)  | 0 | 0 | 1 | 1 |
| C Moore    | 0 | 0 | 1 | 1 |
| C Mealy    | 0 | 1 | 1 | 1 |

The Mealy output moves together with the input (even mid-cycle), the Moore output only after the edge.

* Intuition
Moore answers "where am I?", Mealy answers "where am I and what is happening now?" — the second is quicker and more nervous.

* Pitfall
When several machines talk to each other, a Mealy output feeding another Mealy machine's input whose output comes back closes a loop with no flip-flop in it: possible oscillation. With Moore machines (or registered Mealy outputs) every loop crosses a register. In an [[id:asm-chart][ASM chart]] a Mealy output is a *conditional output* box, never a state.
