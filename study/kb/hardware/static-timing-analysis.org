#+title: Static timing analysis
#+summary: STA checks timing without simulation: on the DAG of the combinational logic between registers it propagates the latest arrival times forward (\(a(v)=\max_{u\to v}a(u)+d_{uv}\)), the required times backward (\(r(u)=\min_{u\to v} r(v)-d_{uv}\)), and reports the slack \(r-a\) of every node; negative slack marks violating paths, in time linear in the circuit size.

* Method
Separation of concerns: functionality is verified by simulation, timing by STA, independently of input values (*static*). Conditions: synchronous design, combinational logic without loops between registers, known delays.

The circuit becomes a timing graph: nodes are pins, edges carry delays. Sources are primary inputs and register outputs (arrival \(t_{cq}\)), sinks are primary outputs and register inputs (required \(T-t_{su}\)).
- *Arrival time* (latest): \(a(v)=\max_{(u,v)}\big(a(u)+d(u,v)\big)\), in topological order.
- *Required time*: \(r(u)=\min_{(u,v)}\big(r(v)-d(u,v)\big)\), in reverse topological order.
- *Slack*: \(s(v)=r(v)-a(v)\). The critical path is the chain of nodes with minimum slack. For hold, the same with earliest arrival (min) and earliest required times.

* Algorithm
#+CAPTION: Static timing analysis: arrival times propagate forward in topological order, required times backward in reverse order, and their difference is the slack of each node.
\begin{algorithmic}[1]
\Require DAG $G=(V,E)$, delays $d$, clock period $T$
\State sort $V$ topologically
\ForAll{$v$ in topological order}
\State $a(v)\gets$ source arrival if $v$ is a source, else $\max_{(u,v)\in E}\, a(u)+d(u,v)$
\EndFor
\ForAll{$v$ in reverse topological order}
\State $r(v)\gets T-t_{su}$ if $v$ is a sink, else $\min_{(v,w)\in E}\, r(w)-d(v,w)$
\EndFor
\State \Return slack $s(v)=r(v)-a(v)$ for all $v$
\end{algorithmic}
Each edge is visited twice: \(O(|V|+|E|)\).

* Intuition
STA asks "how late can each signal possibly be?" once per node, not once per input pattern — which is why it scales to chips that simulation could never cover.

* Pitfall
STA is pessimistic: it counts topological paths that no input can actually sensitise. Those [[id:false-path][false paths]] can make a correct circuit look too slow.
