#+title: False paths
#+summary: A path is false if no input vector can propagate a transition along it, because the conditions that make one gate on the path sensitive force another gate on it into its controlling value; STA's longest topological path may be false, so the true delay of the circuit can be shorter.

* Definition
A gate input is *sensitised* when every other input of the gate holds the non-controlling value (1 for AND/NAND, 0 for OR/NOR; XOR is always sensitised). A path is *statically sensitisable* if some input vector sensitises all its gates at once. A path that no vector sensitises is *false*; the delay of the circuit is the length of its longest *true* path.

* Example
Two multiplexers in series with the same select \(s\): the long path through the "1" input of the first mux and the "0" input of the second needs \(s=1\) for the first and \(s=0\) for the second. No vector does both: the path is false, and the real critical path is shorter than the topological one. Carry-skip adders are built exactly this way: the long ripple path through a block is false when the skip path is taken.

* Intuition
A path is a road on the map; whether a car can drive it depends on the traffic lights, and here the lights are wired never to be green together.

* Pitfall
Declaring paths false by hand (=set_false_path=) is dangerous: a wrong declaration hides a real violation. Multicycle paths (results needed only every \(k\) cycles) are a related, legitimate exception.
